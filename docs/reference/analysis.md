# molclusters.analysis

The analyses run on the tracked clusters. `FrameAnalysis`, `Run` and `Frame` are
in `molclusters.analysis.base`; the registry of built-ins, `BUILTINS`, in
`molclusters.analysis.builtins`; each built-in in a module of its own. All of them
can be imported from `molclusters.analysis`.
